# Generador de Series de Fibonacci en C

## Descripción

Aplicación de consola desarrollada en lenguaje C para generar series de Fibonacci mediante algoritmos eficientes y una estructura modular. Incorpora validación de entradas y control de desbordamiento numérico.

## Características

* Generación de series de Fibonacci.
* Validación de datos de entrada.
* Control de desbordamiento numérico.
* Manejo de errores.
* Interfaz de consola sencilla.
* Código organizado y documentado.

## Tecnologías

* Lenguaje C
* GCC
* Estándar C11

## Requisitos

* Compilador GCC.
* Terminal compatible con la ejecución de programas de C.

## Instalación y ejecución

Compila el programa:

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic -O2 fibonacci.c -o fibonacci
```

Ejecuta en Windows:

```powershell
.\fibonacci.exe
```

## Aplicaciones

* Generación de secuencias numéricas.
* Evaluación de algoritmos.
* Pruebas de lógica y procesamiento numérico.

## Objetivo profesional

Demostrar habilidades en programación estructurada, validación de datos, manejo de errores y desarrollo de aplicaciones de consola en C.
